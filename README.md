# Adaptive Living GraphRAG

## Project Title
Adaptive Living GraphRAG: A Trust-Aware Dynamic Knowledge Evolution Framework for Real-Time LLM Retrieval

## Objective
This project combines GraphRAG, Neo4j, ChromaDB, and Llama 3 to build an intelligent retrieval system that provides trustworthy and explainable answers from research documents.

## Technologies
- Python
- FastAPI
- React
- Neo4j
- ChromaDB
- Ollama
- Llama 3
- LangChain
